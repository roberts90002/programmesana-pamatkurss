## Kā palaist?
Lai **palaistu** manu programmu:

- Atver projekta mapi VS Code.
- Atver programmas galveno failu.
- Palaid programmu ar VS Code palaišanas pogu.
- Pārbaudi programmas darbību un rezultātu.
